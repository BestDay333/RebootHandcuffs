# RebootHandcuffs

Плагин для Minecraft-серверов (**Paper 26.3**) с механикой наручников для RP-серверов:
заковывание игроков предметом, физика «поводка», сохранение состояния между рестартами
и ограничения действий для закованных.

> **Версия 2.0** — плагин переписан под Paper **26.3** (Java **25**).

## Особенности

- **Наручники-предмет**: правый клик по игроку предметом `Наручники` (материал и название настраиваются)
- **Физика поводка**: жертва притягивается к «судье», если он ушёл дальше `max-distance`; нарисованы частицы-поводок
- **Сохранение**: закованные игроки и их предметы из рук переживают рестарт (`handcuffs.yml`)
- **Без потери предметов**: содержимое рук возвращается в инвентарь, а не удаляется
- **Ограничения**: ломать/ставить блоки, атаковать (в том числе из лука), получать урон,
  открывать инвентари, выбрасывать предметы, ездить на транспорте и т.д. — всё включается/выключается в конфиге
- **Админ-команды**: `/cuff`, `/uncuff` (работает и с оффлайн-игроками), `/cuffgive`, `/cufflist`, `/cuffreload`

## Требования

| Компонент | Версия |
|-----------|--------|
| Сервер | Paper **26.3** (плагин собран под `api-version: 26.3`) |
| Java | **25 или новее** (Paper 26.1+ работает только на Java 25) |
| Gradle | 8.10+ (для сборки из исходников; JDK 25 должен быть установлен локально) |

## Сборка

### Windows

```powershell
.\build.ps1
```

Скрипт сам найдёт JDK 25 и Gradle и выполнит `gradle clean build`.

### Linux / macOS / Git Bash

```bash
chmod +x build.sh
./build.sh
```

### Вручную

```bash
gradle clean build
```

Готовый файл: `build/libs/RebootHandcuffs-2.0.1.jar` (копия кладётся и в корень проекта).

> Зависимости (`paper-api` и транзитивные) берутся сначала из локального `~/.m2` (`mavenLocal()`),
> затем с `repo.papermc.io`. Если Paper API уже установлен локально, сборка работает и без сети.

## Установка

1. Положите `RebootHandcuffs-2.0.1.jar` в папку `plugins` вашего сервера.
2. Перезапустите сервер.
3. Выдайте наручники: `/cuffgive <ник> 1` (или `/cuffgive` себе).
4. Настройте плагин в `plugins/RebootHandcuffs/config.yml` и выполните `/cuffreload`.

## Команды

| Команда | Описание | Разрешение |
|---------|----------|------------|
| `/cuff <игрок>` | Заковать игрока | `reboot.admin` |
| `/uncuff <игрок>` | Снять наручники (работает с оффлайн-игроками: предметы вернутся при входе) | `reboot.admin` |
| `/cuffgive [игрок] [кол-во]` | Выдать предмет «Наручники» | `reboot.admin` |
| `/cufflist` | Список закованных игроков | `reboot.admin` |
| `/cuffreload` | Перезагрузить конфигурацию | `reboot.admin` |

Все команды доступны из консоли.

## Разрешения

| Разрешение | Описание | По умолчанию |
|------------|----------|--------------|
| `reboot.judge` | Право использовать предмет наручников (если `permission: "reboot.judge"`) | op |
| `reboot.admin` | Доступ к админ-командам | op |

## Конфигурация

Файл: `plugins/RebootHandcuffs/config.yml`

```yaml
permission: "op"          # "op" или узел разрешения, например "reboot.judge"
message-display: actionbar  # actionbar | chat | title
message-format: legacy      # legacy (&c / §c) | minimessage (<red>)

msg-cuff: "&c✖ ВЫ СВЯЗАНЫ ✖"
msg-uncuff: "&aНаручники сняты"
msg-judge-success: "&aИгрок закован"
msg-still-cuffed: "&c✖ ВЫ ВСЕ ЕЩЕ СВЯЗАНЫ ✖"
# ... остальные сообщения см. src/main/resources/config.yml

cuff:
  material: LEAD           # материал предмета-наручников
  name: "Наручники"        # название предмета
  delay-ticks: 15          # задержка заковывания
  uncuff-delay-ticks: 20   # задержка снятия
  cooldown-ticks: 20       # кулдаун по одной цели (защита от двойного клика)

max-distance: 1.5          # дистанция, с которой жертву начинает тянуть к судье
pull-strength: 0.15        # сила притяжения за блок превышения (раньше не использовалась!)
max-pull-strength: 0.8     # предел силы притяжения
height-follow: 0.12        # плавное следование по высоте

particles:
  enabled: true
  type: END_ROD
  every-n-ticks: 2         # отрисовка поводка раз в N тиков
  density: 2.0             # частиц на блок
  max-points: 24
  max-distance: 32.0
  receivers: 48            # радиус видимости частиц

restrictions:
  allow-move: false
  allow-break: false
  allow-place: false
  allow-attack: false
  allow-damage: false
  allow-inventory: false
  allow-drop: false
  allow-swap-hands: false
  allow-vehicles: false
  never-block-damage-causes: [VOID, KILL]   # иначе можно застрять в пустоте
```

## Что изменилось в 2.0

### Исправленные баги

1. **Сообщения не красились** — `&c...` десериализовалась через `legacySection()`,
   игроки видели literal `&c✖ ...`. Теперь поддерживаются и `&`, и `§`, и MiniMessage.
2. **Краш при разных мирах** — `victimLoc.distance(judgeLoc)` бросал `IllegalArgumentException`,
   если жертва и судья в разных мирах (ошибка в консоли каждый тик).
3. **Потеря предметов из рук** — предмет, поднятый в руку, затирался при возврате;
   при логине руки просто обнулялись. Теперь всё перекладывается в инвентарь,
   а если места нет — предметы выбрасываются под ноги.
4. **Поворот головы** — `event.setTo(from)` в `PlayerMoveEvent` сбрасывал yaw/pitch.
   Теперь откатывается только позиция, поворот головы полностью работает.
5. **Дёрганье жертвы** — каждый тик жертве записывалась скорость судьей (`judgeVel * 0.7`),
   что конфликтовало с блокировкой движения. Убрано: жертва стоит, пока судья не отойдёт.
6. **`pull-strength` не работал** — значение из конфига игнорировалось (сила была захардкожена).
7. **Версии не совпадали** — `plugin.yml` говорил `1.0`, `pom.xml` — `1.5`. Теперь версия
   подставляется из `build.gradle.kts` при сборке (`2.0.0`).
8. **Стрельба из-под наручников** — атаки снарядами (лук, арбалет, тризубец) не блокировались.
9. **Транспорт обходил блокировку** — в лодке/вагонетке PlayerMoveEvent не срабатывает.
   Теперь закованных автоматически «высаживают» из транспорта.
10. **Урон VOID** — блокировался вместе со всем, из-за чего игрока можно было навсегда
    запереть в пустоте. Причины из `never-block-damage-causes` больше не блокируются.
11. **Жертва не шла за судьёй** (2.0.1) — блокировка движения откатывала **все** перемещения,
    включая те, что создавала физика поводка: жертва дёргалась на месте. Теперь закованный
    может двигаться в радиусе `max-distance`, а за границей радиуса его плавно тянет за
    уходящим судьёй (движение прижимается к границе «поводка», а не откатывается).
    Сила притяжения теперь равна скорости судьи — жертва идёт ровно за ним.
12. **Частицы поводка не были видны** (2.0.1) — получатели частиц вычислялись до установки
    позиции, список получателей выходил пустым, и частицы не отправлялись никому.
    Теперь получатели считаются от позиции жертвы.

### Улучшения

- Команды `/cuff` и `/uncuff` теперь доступны **из консоли**; `/uncuff` работает с **оффлайн**-игроками
  (предметы вернутся игроку при следующем входе).
- Новые команды: `/cuffgive`, `/cufflist`, `/cuffreload`.
- Идентификация предмета наручников по **PDC-метке** (не зависит от локали/регистрара названия),
  название из конфига поддерживается для совместимости.
- Кулдаун между использованиями предмета + защита от двойного клика
  (отложенные задачи отменяются, при выходе игрока — тоже).
- Новые ограничения: `allow-move`, `allow-inventory`, `allow-drop`, `allow-swap-hands`, `allow-vehicles`.
- Формат сообщений: `actionbar` / `chat` / `title`, `legacy` / `minimessage`.

### Оптимизация

- Значения конфигурации кэшируются (`PluginSettings`) — обработчики событий и задача физики
  больше не читают YAML на каждое событие.
- Запись `handcuffs.yml` перенесена в **отдельный поток** и сделана **атомарной**
  (временный файл + `Files.move`), главный поток сервера не блокируется, файл не портится при краше.
- Старый формат файла загружается и автоматически мигрирует в новый.
- `CuffTask` не работает с пустым списком, перескакивает пары в разных мирах, считает
  квадрат расстояния без `sqrt`, переиспользует буфер записей, один `ParticleBuilder` и `Location`.
- Частицы поводка отправляются только игрокам в радиусе `particles.receivers` и не чаще
  `particles.every-n-ticks`.
- В `PlayerMoveEvent` проверка идёт по границе блока (меньше срабатываний) и с
  `ignoreCancelled = true`.
- Убрана ненужная зависимость shade-плагина (плагин не бандлит библиотек).
