# RebootHandcuffs

Плагин для Minecraft серверов (Paper/Spigot), добавляющий механику наручников для RP-серверов.

## Особенности

- **Механика наручников**: Заковывайте игроков в наручники с помощью предмета
- **Физика движения**: Ограничение передвижения закованных игроков
- **Сохранение данных**: Информация о закованных игроках сохраняется и загружается при перезапуске
- **Настройка ограничений**: Контроль действий закованных игроков (ломать блоки, ставить блоки, атаковать и т.д.)
- **Административная команда**: Снятие наручников через команду `/uncuff`

## Требования

- Java 17 или выше
- Paper/Spigot 1.20.4 или выше
- Maven (для сборки из исходного кода)

## Сборка

### Использование скрипта сборки

```bash
chmod +x build.sh
./build.sh
```

### Ручная сборка через Maven

```bash
mvn clean package
```

Собранный JAR-файл будет находиться в папке `target/` как `RebootHandcuffs-1.0.jar`

## Установка

1. Поместите `RebootHandcuffs-1.0.jar` в папку `plugins` вашего сервера
2. Перезапустите сервер
3. Настройте плагин в файле `config.yml`

## Команды

| Команда | Описание | Разрешение |
|---------|----------|------------|
| `/uncuff <игрок>` | Снять наручники с игрока | `reboot.admin` |

## Разрешения

| Разрешение | Описание | По умолчанию |
|------------|----------|--------------|
| `reboot.judge` | Право использовать наручники | OP |
| `reboot.admin` | Доступ к административным командам | OP |

## Конфигурация

Файл конфигурации находится по пути: `plugins/RebootHandcuffs/config.yml`

```yaml
# Режим разрешений: "op" для операторов или строка разрешения типа "reboot.judge"
permission: "op"

# Сообщения (используются legacy color codes)
msg-cuff: "&c✖ ВЫ СВЯЗАНЫ ✖"
msg-uncuff: "&aНаручники сняты"
msg-judge-success: "&aИгрок закован"
msg-still-cuffed: "&c✖ ВЫ ВСЕ ЕЩЕ СВЯЗАНЫ ✖"

# Настройки физики
max-distance: 1.5
pull-strength: 0.4

# Ограничения для закованных игроков
restrictions:
  allow-break: false    # Ломать блоки
  allow-place: false    # Ставить блоки
  allow-attack: false   # Атаковать
  allow-damage: false   # Получать урон
```
